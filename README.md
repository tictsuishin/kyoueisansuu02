# 算数の振り返りアプリ

小学校の算数の授業で使う振り返りフォームです。課題のまとめや学び方、自己評価を記録し、自己評価の変化と過去のまとめを確認できます。

## 使い方

ブラウザで `index.html` を開くか、リポジトリのルートでローカルサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。記録はブラウザの `localStorage` に保存されます。
